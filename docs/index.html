Project

Quantum Tumtum is a collection of GPU-powered quantum-circuit simulation examples. These run on a simulator, not on a physical quantum computer. The capacity benchmark uses memory estimates and a reserve, but GPU workloads and simulator overhead vary.

On an NVIDIA GeForce RTX 3050 with 4 GB VRAM, the recorded benchmark completed a 27-qubit double-precision statevector and stopped before attempting 28 qubits. The QAOA sample, run with 8,192 shots, measured a mean cut of 20.238/27 against a random-assignment baseline of 13.5/27; it sampled the exact odd-cycle optimum of 26/27 on 23 shots. Results are one recorded run, not a performance guarantee.

A separate Colab benchmark run reported 15,360 MiB total VRAM and completed a 28-qubit double-precision statevector (4,096 MiB). It used a 40% VRAM cap (6,144 MiB), a 2,048 MiB reserve, and a 1.5x overhead estimate; it stopped before 29 qubits, estimated at 12,288 MiB. The GPU model was not reported. See the per-qubit timings. GPU capacity varies by device and load.
